# Skibidibi Git Support

Use [GitHub Issues](https://github.com/rbrzoska/skibidibi-git/issues) for bug reports, feature
requests, update problems, and privacy questions.

Before opening an issue:

1. Check that the issue still occurs in the latest published version.
2. Include the Skibidibi Git version, operating system version, and a short reproduction.
3. If useful, copy only the relevant redacted diagnostic events from **Settings → Diagnostics &
   application data → View log**.

Never publish access tokens, SSH keys, private source code or diffs, confidential repository URLs,
or other personal or company data. Skibidibi Git never requires credentials in a support issue.

## System requirements

- 64-bit Windows 10 or Windows 11, macOS, or a supported x64 Linux distribution.
- A system Git installation available on `PATH`.
- Keyboard or mouse/trackpad.
- Network access only for remote Git operations, GitHub integration, update checks, and optional AI
  CLI features.

Optional integrations require their corresponding tools or accounts, such as GitHub CLI, Codex,
Claude, Cursor, VS Code, or Cursor Editor.
