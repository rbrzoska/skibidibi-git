# Decision record template

```markdown
# <decision title>
> Date: YYYY-MM-DD
> Status: proposed | accepted | superseded

## Context
<constraint and problem>

## Decision
<choice and boundary>

## Consequences
<benefits, trade-offs, compatibility/security/performance impact>

## Validation
<how the decision will be checked>
```

Use this for durable architectural, dependency, data-contract, or security decisions—not routine implementation details.
