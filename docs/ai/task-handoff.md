# Task handoff template

```markdown
## Outcome
<what changed and why>

## Files owned/changed
- `<path>` — <purpose>

## Validation
- `<command>` — passed / failed / unavailable: <short detail>

## Decisions and risks
- <contract, compatibility, security, or performance note>

## Next step
- <only if action remains>
```

Keep handoffs factual. Mention unrelated pre-existing work without claiming or modifying it.
